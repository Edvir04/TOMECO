  QUICK START GUIDE - Running TOMECO Servers in CMD
═══════════════════════════════════════════════════════════════

METHOD 1: Using Batch Files (EASIEST)
═══════════════════════════════════════════════════════════════

Step 1: Open Command Prompt
   - Press Windows Key + R
   - Type: cmd
   - Press Enter

Step 2: Navigate to Project Folder
   cd C:\Users\Charles Rosete\Capstone_Gigs\tomeco_web

Step 3: Run Admin Server (First Terminal)
   start-admin-server.bat
   
   ✓ Admin Portal will start at: http://localhost:8000

Step 4: Run Violator Server (Second Terminal)
   - Open a NEW Command Prompt window
   - Navigate again: cd C:\Users\Charles Rosete\Capstone_Gigs\tomeco_web
   - Run: start-violator-server.bat
   
   ✓ Violator Portal will start at: http://localhost:8001


METHOD 2: Manual Commands
═══════════════════════════════════════════════════════════════

TERMINAL 1 - Admin Server:
───────────────────────────────────────────────────────────────
cd C:\Users\Charles Rosete\Capstone_Gigs\tomeco_web
set APP_PORTAL_TYPE=admin
php artisan serve --port=8000

TERMINAL 2 - Violator Server:
───────────────────────────────────────────────────────────────
cd C:\Users\Charles Rosete\Capstone_Gigs\tomeco_web
set APP_PORTAL_TYPE=violator
php artisan serve --port=8001
