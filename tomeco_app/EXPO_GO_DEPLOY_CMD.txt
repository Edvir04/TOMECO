================================================================================
TROUBLESHOOTING
================================================================================

Problem: "Network request failed"
Solution:
  1. Check ngrok is running: http://127.0.0.1:4040
  2. Test: curl https://Tomeco.ngrok.dev/api/mobile/health
  3. Verify backend is running on port 8000

Problem: "Cannot connect to Expo"
Solution:
  1. Make sure phone and computer are on same WiFi
  2. Try: npx expo start --tunnel

Problem: "QR code not working"
Solution:
  1. Use tunnel mode: npx expo start --tunnel
  2. Or manually enter URL in Expo Go app
